# Vinayak Pawate — Engineering Portfolio Website

A premium, modern, and high-performance personal portfolio website for **Vinayak Pawate**, Computer Engineering student and Full-Stack Software Developer with complementary strengths in Data Analytics and AI.

Built to communicate technical depth, product focus, and algorithmic rigor—inspired by the precision minimalism of **Apple, Linear, Stripe, and Vercel**, designed using **Google Stitch**.

---

- **Icons**: [Lucide React](https://lucide.dev/)

## 🏃 Local Development

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

---

## 📦 Production Build

```bash
# Build production bundle
npm run build

# Start production server
npm run start
```
